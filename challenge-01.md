# Challenge 1 : Linux Service Management

> **Prerequisite:** You need a Linux system (Ubuntu/Debian preferred). WSL on Windows is fine.

Pick **any** running service on your system (e.g. `ssh`, `nginx`, `cron`, or anything else).

Do the following and document every command you used:

1. Check if the service is running and find its PID
2. Stop the service
3. Confirm it stopped (verify the PID is gone)
4. Start the service again
5. Kill the process directly using its PID (not via systemctl)
6. Check the service status after killing it

Write your answers in the README. There is no single correct answer, just show what you did and what output you got. Include screenshots where the output is visible.
