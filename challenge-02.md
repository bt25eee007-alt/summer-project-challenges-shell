# Challenge 2 : OSQuery Setup and Exploration

> **Prerequisite:** You need a Linux system (Ubuntu/Debian preferred). WSL on Windows is fine.

1. Install OSQuery on your Linux system. Write down the exact steps you followed. Keep it short, just enough to reproduce it.
2. Start the OSQuery service. Take a screenshot.
3. Stop the OSQuery service. Take a screenshot.
4. Open the OSQuery interactive shell (`osqueryi`).
5. Run SQL queries to get the following and paste the full JSON output in a code block:
   - System info
   - Platform info
   - Battery info (if available. If not, note why and show what you tried)
